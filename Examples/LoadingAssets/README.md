An application demonstrating how to load assets: A chess set model loaded from a glTF (`.glb`) file and a baked backdrop texture, viewed with an inspector camera, with keys to toggle the backdrop and add lights.

For more explanation see: [https://tinyffr.dev/tutorials/loading_assets/](https://tinyffr.dev/tutorials/loading_assets/).
