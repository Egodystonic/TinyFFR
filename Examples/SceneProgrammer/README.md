A showcase application: A small scene editor built with [Avalonia](https://avaloniaui.net/). Import models, arrange them in a scene, set up the lighting, and program a camera "fly-through" track by capturing keyframes from the editor's camera. Press Play to watch the result in a separate fullscreen window that's rendered entirely by TinyFFR, at an uncapped framerate.

For more explanation see: [https://tinyffr.dev/tutorials/scene_programmer/](https://tinyffr.dev/tutorials/scene_programmer/).

## Controls

| Action | Control |
| :-- | :-- |
| Select an object | Left click |
| Move the selected object along the ground | Left drag |
| Raise or lower the selected object | Shift + left drag |
| Fly the editor camera | Hold right mouse button + move mouse, W / A / S / D, Q / E (down / up), Left Shift (faster) |
| Change fly speed | Mouse wheel |
| Add a camera keyframe at the current view | K |
| Delete the selected object | Delete |
| Exit fullscreen playback | Escape |
