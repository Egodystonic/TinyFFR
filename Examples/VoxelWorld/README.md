A showcase application: An infinite, procedurally generated voxel world that's streamed in around a first-person player as they explore. Terrain generation and chunk meshing run on background threads, and the whole application avoids generating garbage after start-up.

For more explanation see: [https://tinyffr.dev/tutorials/voxel_world/](https://tinyffr.dev/tutorials/voxel_world/).
