An application demonstrating how to draw a 2D overlay over a 3D scene with a canvas scene: Light counts with icons in the top-left corner, and clickable buttons in the bottom-right corner that change the hue and brightness of the most recently placed light.

For more explanation see: [https://tinyffr.dev/tutorials/adding_a_2d_overlay/](https://tinyffr.dev/tutorials/adding_a_2d_overlay/).
