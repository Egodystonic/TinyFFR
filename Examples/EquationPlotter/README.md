A showcase application: An interactive plotter for equations of three dimensions plus time. Type in an equation and watch it animate as a height surface, a field of arrows, a parametric surface, or a slice through a 3D scalar field. The controls are drawn with Dear ImGui, and the camera orbits the plot.

For more explanation see: [https://tinyffr.dev/tutorials/equation_plotter/](https://tinyffr.dev/tutorials/equation_plotter/).

## Controls

| Action | Control |
| :-- | :-- |
| Orbit the camera | Hold left or right mouse button + move mouse |
| Zoom | Mouse wheel |
| Apply an edited equation | Enter (or the Apply button) |
| Exit | Escape |
