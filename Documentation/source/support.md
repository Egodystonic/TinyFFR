## :simple-discord: Discord

TinyFFR has a discord server for realtime support: [:simple-discord: TinyFFR Discord](https://discord.gg/5vMDq7znwj)

## :simple-github: GitHub

You can also use the [discussions](https://github.com/Egodystonic/TinyFFR/discussions) tab on GitHub; and/or raise an [issue](https://github.com/Egodystonic/TinyFFR/issues).

## :material-cube: This Site

Every page in this site has a discussion section at the bottom where you can ask questions or seek clarifications. Check at the bottom of the page to see if your question might already have been answered!
